# tools_nro

Mod DragonBoy 2.5.0 PC (Ngọc Rồng Online)

## Tính năng
- Phím tắt F2: Mở bảng cài đặt Mod
- J, K, L: Dịch map tức thì (Trái, Giữa, Phải) - hỗ trợ cả cổng trên không như tàu bay Đảo Bulông
- Tàn sát thông minh (khóa mục tiêu, hỗ trợ TDLT)
- Auto nhặt đồ, auto buff đậu, auto dùng vật phẩm
- Auto hồi sinh, auto đóng băng quái
