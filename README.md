# tools_nro

Mod DragonBoy 2.5.0 PC (Ngọc Rồng Online)

## Tính năng
- **Bảng Quản Lý Tài Khoản (QLTK_DragonBoy.exe)**:
  - Giao diện trực quan, an toàn sạch 100% (không kết nối mạng, không lộ mật khẩu).
  - Quản lý danh sách tài khoản: Thêm, Sửa, Xoá, Chọn Server (1 -> 15), Ghi chú.
  - Chọn kích thước cửa sổ game (Rộng x Cao), số cột hiển thị.
  - Tự động mở game theo lưới (Grid tiling) và tự động đăng nhập đúng tài khoản + đúng server.
  - Nút "▶ Chạy Nick Chọn", "🚀 Chạy Tất Cả", "⛔ Đóng Hết Game".
- **Bảng Chọn Nick Ngay Trong Game (In-Game Account Selector)**:
  - Ở màn hình đăng nhập / chọn server: Nút **"Chọn Nick QLTK"**.
  - Ở Menu đăng nhập: Chọn **"Chọn Nick QLTK"**.
  - Trong game: Chat lệnh `/qltk` hoặc `/acc` để đổi nick nhanh.
  - 1-click chọn nick từ file `Data/accounts_safe.txt` là vào game ngay không cần gõ mật khẩu.
- **Phím tắt**:
  - `F2`: Mở bảng cài đặt Mod tổng hợp.
  - `J`, `K`, `L`: Di chuyển nhanh tới các điểm chuyển map (Trái, Giữa, Phải).
- **Auto Farm**:
  - Tàn sát thông minh (khóa mục tiêu, hỗ trợ TDLT).
  - Auto nhặt đồ, auto buff đậu, auto dùng vật phẩm.
  - Auto hồi sinh, auto đóng băng quái.
